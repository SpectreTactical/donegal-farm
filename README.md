# Donegal Farm – Herd Tracker

An offline herd tracker for Donegal Farm. It records calvings per season, weaned calves, auction sales, prices and herd movements.

Open the app at https://spectretactical.github.io/donegal-farm/

Everything you enter is saved in the browser on your own device; this repository holds no farm data. Use **Data → Export backup** to keep a copy or to move records to another device, and **Import** to load one.
